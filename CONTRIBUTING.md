# Правила работы

Одни и те же для трёх репозиториев: [PictoLex](https://github.com/UsusCimex/PictoLex) (Android-приложение), [InferGate](https://github.com/UsusCimex/InferGate) (шлюз к моделям) и [диплом](https://github.com/UsusCimex/NSU_MastersDegreeThesis_PictoLex).

## Задачи

- Планы, идеи и известные проблемы ведутся в Issues своего репозитория. Задача на два репозитория заводится там, где основная работа, со ссылкой на второй (`UsusCimex/InferGate#30`).
- Метки: `bug` ошибка, `enhancement` новая возможность или материал, `performance` скорость и память, `refactor` устройство кода без изменения поведения, `documentation` документация, `chore` обслуживание, `question` нужно решение автора.
- Коммит, который решает задачу, заканчивается строкой `Closes #N`.

## Коммиты

- Заголовок `тип(область): что сделано`: по-английски, со строчной буквы, в повелительном наклонении, без точки в конце, до 72 символов.
- Типы: `feat` новая возможность или материал, `fix` исправление, `perf` скорость и память, `refactor` перестройка без изменения поведения, `docs` документация и заметки, `test` тесты, `build` сборка, зависимости, CI и релизы, `chore` прочее.
- Область: модуль или папка (`ui`, `stories`, `gateway`, `worker`, `text`, `experiments`). Если изменение общее, область не пишется.
- Тело по желанию: пустая строка, затем пункты `- `, по одному факту в пункте.
- Один коммит, одно законченное изменение. Без `Co-Authored-By` и других приписок.

```
fix(stories): keep one string per tale scene

- the prompt asks for exactly 8 lines
- JsonCleaner repairs a list closed with a brace

Closes #12
```

## Ветки

- Работа идёт прямо в `main`, без pull request.
- Изменение, которое ждёт согласования автора (текст диплома), идёт в ветку `text/<тема>` и вливается в `main` merge-коммитом после показа было/стало. Влитая ветка удаляется.

## Перед пушем

- Проверки проходят: PictoLex `./gradlew :app:testDebugUnitTest`, InferGate `ruff check app/ tests/` и `pytest`, диплом `python thesis/generate_dissertation.py`, если менялся текст.
- В изменениях нет ключей, токенов и личных данных.
- Документация, которую затронуло изменение, поправлена в том же коммите.

## Версии

Версию ведёт только PictoLex: `Beta MAJOR.MINOR.PATCH` по SemVer в `app/build.gradle.kts`. Номер меняется в коммите с видимым изменением, пуш новой версии в `main` публикует релиз с APK. У InferGate и диплома версий нет, состояние определяет коммит.

## Языки

Документация, задачи и интерфейс по-русски, код, комментарии и коммиты по-английски. Каждая строка интерфейса PictoLex есть на русском и английском.

## Тексты

- Только необходимый минимум: без вступлений, пересказа кода и очевидного. Если понятно без текста, текста нет.
- Только символы с клавиатуры: дефис вместо длинного и среднего тире, без стрелок (и без `->` в тексте), прямые кавычки, три точки, `x` и `~` вместо знаков умножения и приближения.
- Исключения: главы диплома (русская типографика), промты моделей и отчёты, которые пишут скрипты.

## Комментарии в коде

- По умолчанию комментариев нет: понятное имя лучше комментария.
- Doc-комментарий (KDoc, docstring) в одно-два предложения у публичного объявления, если имени и сигнатуры мало. У скрипта, который запускают руками, docstring модуля со строками запуска.
- Строка внутри кода только ради неочевидного: внешний контракт, скрытый инвариант, обход чужой ошибки.
- Нельзя: история изменений, ссылки на задачи, даты и версии, многоабзацные блоки, метки шагов, разделители секций, пересказ кода, закомментированный код, TODO без владельца.
